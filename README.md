# Responsive Flexbox Layout

A CSS practice project focused on creating a responsive layout using **CSS Flexbox** and **Media Queries**.

The project demonstrates how a horizontal layout on desktop can automatically change to a vertical layout on smaller screens without using `flex-wrap`.

## 📌 Project Overview

This project contains a simple container with three boxes displaying a welcome message.

On larger screens, the boxes are arranged horizontally using Flexbox.

On smaller screens, a media query changes the Flexbox direction from `row` to `column`, making the boxes stack vertically.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- Media Queries
- Viewport Units (`vh`, `vw`)
- CSS `box-sizing`
